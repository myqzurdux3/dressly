# Persisted user data

Everything in this directory is real user data — **never delete it**.

* `data.db` (and `data.db-wal`, `data.db-shm`) — SQLite database.
* `images/` — uploaded cloth + model photos and their background-removed cutouts.
* `outfits/` — generated outfit images.

The schema is `CREATE TABLE IF NOT EXISTS` and uses additive migrations only,
so the DB is reused across restarts. The path is computed absolutely from this
file's location (`config.py`), so the same DB file is used no matter which
directory uvicorn was launched from.

If you want a throwaway DB for testing, set `CLOTHESAPP_DATA_DIR=/tmp/whatever`
in the environment before starting the server — your real data here is then
untouched.
